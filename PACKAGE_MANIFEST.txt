Security:
- .env is NOT included
- Use your production .env on the server

Deployment:
1. composer install --no-dev --optimize-autoloader
2. php artisan migrate --force
3. php artisan db:seed --class=CanvaTemplatesSeeder --force
4. php artisan db:seed --class=OfficeTemplateLibrarySeeder --force
5. php artisan storage:link
6. php artisan optimize:clear
